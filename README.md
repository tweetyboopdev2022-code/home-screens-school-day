# School Day — a Home Screens plugin

Today's or tomorrow's school cycle day (Day 1–5), the classes on it, what to bring, upcoming tests and library returns from the calendar, and storm-closure alerts.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-school-day/releases/latest/download/school-day.tgz
```

Build: `npm install && npm run build`
